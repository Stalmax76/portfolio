## 🧩 Architecture & Approach

- **Vanilla‑first** — no frameworks, full control over code
- **Component‑based structure** — each section is an independent module
- **Mobile‑first** — adaptive layout from small to large screens
- **Clean code** — readable, maintainable, scalable
- **UX‑focused** — animations only where they improve experience
- **Performance‑oriented** — optimized assets and lightweight scripts
- **Honest stack** — only technologies actually used in the project

## 📦 Main Components

### **Header**

Responsive navigation with active states, mobile menu, smooth animations, and a scroll‑aware logo. Built with BEM and lightweight JS.

### **Hero**

Strong introductory section with expressive typography, highlighted keywords, adaptive spacing, and soft reveal animations.

### **About**

Portrait + four modular “aboutcard” components. Sticky behavior on desktop, semantic structure, optimized images.

### **Skills**

Grid of six skill cards with titles, descriptions, and tech lists. Fully responsive and component‑driven.

### **Projects**

A curated showcase of selected work:

- Modular `projectcard` components
- Desktop tabs + mobile dropdown
- JavaScript‑driven filtering
- Smooth staggered animations
- Adaptive grid layout
- Accessible controls with ARIA

### **Progress**

Timeline‑style section showing skill development and growth.

### **Contact**

Accessible contact form with validation, auto‑height textarea, and social links with aria‑labels.

### **Footer**

Semantic `contentinfo` footer with navigation, CV link, and copyright.
