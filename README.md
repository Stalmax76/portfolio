# VasylS. — Portfolio Website

A fast, responsive, and accessible personal portfolio built with **HTML**, **SCSS**, and **JavaScript**.  
The project showcases my frontend skills, component‑based thinking, and attention to UX and performance.

---

## 🚀 Live Demo

_[https://stalmax76.github.io/portfolio/]_

---

## 🛠️ Tech Stack

- HTML5 (semantic)
- SCSS (BEM, modular)
- JavaScript (ES6+)
- Vite (build & dev server)
- GSAP (animations)
- Git / GitHub

---

## 📦 Features

- Fully responsive, mobile‑first layout
- Component‑based architecture
- Smooth animations & micro‑interactions
- Optimized images & SVGs
- Accessible markup with ARIA
- Light/Dark theme with saved user preference
- Project filtering (desktop tabs + mobile dropdown)

---

## 🧩 Main Sections

- **Header** — adaptive navigation + mobile menu
- **Hero** — intro with strong typography and CTAs
- **About** — portrait + modular info cards
- **Skills** — grid of skill cards
- **Projects** — filterable showcase with animations
- **Progress** — timeline of skill development
- **Contact** — accessible form + social links
- **Footer** — navigation + CV link

---

## ⚡ Performance

- Lazy loading
- Minified CSS/JS
- Image compression
- Fast Vite build
